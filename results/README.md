# Benchmark Results

These JSON files are **illustrative examples** generated by the dynamo mocker stack — not real GPU measurements.

The mocker simulates disaggregated inference timing by parameterising KV-cache transfer bandwidth. Compute time (`--speedup-ratio 0`) is suppressed so latency is dominated by the simulated transfer delay. This cleanly demonstrates the placement effect without requiring physical GPUs.

## Files

| File | Scenario | KV Bandwidth | p50 | p99 | Throughput |
|------|----------|-------------|-----|-----|------------|
| `same-rack.json` | Prefill + decode on rack-01 | 400 GB/s (NVLink analog) | 9.4 ms | 12.6 ms | 374 req/s |
| `cross-rack.json` | Prefill rack-01, decode rack-02 | 12.5 GB/s (100 GbE inter-rack) | 28.3 ms | 29.9 ms | 136 req/s |

**~3× latency and ~2.7× throughput difference** between placements at ISL=4096, OSL=32, concurrency=4.

## Reproducing

```bash
make phase3-same-rack   # deploy same-rack scenario
make run-benchmark      # run aiperf, saves results/same-rack.json

make phase3-cross-rack  # deploy cross-rack scenario
make run-benchmark      # run aiperf, saves results/cross-rack.json

make compare-results    # print side-by-side table
```
